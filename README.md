# 黄胜泽 · 技术履历与研究专题

网站：https://huangshengzebluesky.github.io/

网站展开技术细节，三页图文简历说明个人贡献、关键方法与结果。内容覆盖12个专题，通过学习路径组织场景工程、组件自进化、论文阅读及人机协作。

## 内容与维护

- `content.json` 的 `projects`：专题摘要、正文、流程、对照表、公开来源和可交互修改面。
- `content.json` 的 `learning`：路线索引及 AutoPE、AutoHarness、RewardWeaver 的方法对照。
- `content.json` 的 `resume_profile`：图文简历唯一文字来源，网页和 LaTeX 共用。
- `scripts/sync_resume.py`：同步简历文字到既有 LaTeX 文件，不编译，不更换编辑器。
- `resume.tex`：当前可编辑的简历。使用编辑器编译并导出 PDF。
- `resume.pdf`：与当前 LaTeX 同步导出的最新三页简历，网页提供直接下载。
- `build.py` 和 `assets/`：静态页面生成及阅读界面，无前端依赖。

更新正文后运行：

```bash
python3 scripts/sync_resume.py
python3 build.py
```

正在编辑另一位置的既有源文件时，可用 `--latex-path /absolute/path/resume.tex` 同步；编辑器会自动更新预览。不要在编辑期间另建替代文档。

推送到 `main` 后自动发布 GitHub Pages。PDF须从当前 LaTeX 导出后同步替换，并随网页一同发布。

## 表述原则

论文作者与研究参与者分别记录；训练集对照、单案例机制演示、留出集与业务效果分别陈述。方法版本数量不代表有效算法数量，评分通过不代表所有行为都正确。个人专题中教学示例与实际实验分开，公开内容不包含客户原始数据或私人会话。

## 专题与设计维护

`content.json.projects` 保存12个专题的正文。章节支持段落、流程、对照表、公式、代码示例和提示框；教学数据须明确注明。`presentation.json` 单独维护每篇的关键问题、阅读要点与交互机制图步骤。首页、索引和专题页共用这些内容，避免卡片标题和正文漂移。

`build.py` 生成首页、分类与搜索索引、97节技术内容及简历页。机制图是根据实现重绘的解释图，不是运行截图。`assets/site.js` 提供优化对象切换、分类搜索、图解步骤切换、修改面选择和阅读位置导航；所有正文无需JavaScript也可阅读。

新增内容优先写清真实实现、个人贡献与教学延伸的区别。论文内容引用官方论文与代码；本地路径、内部来源笔记与私人会话不进入公开页面。简历PDF独立维护，网站正文扩写不自动改动PDF。

## 开源项目入口

`open-source.json` 维护首页公开项目目录，按智能体评测、自动实验与协作、模型与知识学习、个人应用分类。每项包含简介、仓库入口及可选的在线文档。更新后运行 `python3 build.py`，推送至 `main` 自动发布。
