\section{实习经历}
\entry{元理智能}{AutoHarness 算法负责实习生}{2026.01--2026.10}
\begin{itemize}
\item \textbf{AutoHarness 与实验工作台：}负责运行组件的修改面设计，基于 Pydantic Agent 明确配置边界，在 DeepSeek Harness 中实现方法级插件装配；结合监控、归因、优化三会话与交互看板，连接失败分析、候选评测和版本晋升。
\item \textbf{受控优化结果：}在模型、任务及预算一致的 Telecom 训练集 74 题$\times$3 次对照中，提示词与工具结果插件使成功率由 29.73\% 提升至 60.81\%（增加 31.08 个百分点）；完成全量轨迹与插件实际生效核验。
\item \textbf{金融 Agent 沙箱迁移：}将 13 个远端业务工具迁移为本地 Python/SQLite 实现，保留调用接口；分离业务、记忆、历史三库，关联模型请求、工具执行和数据库变化，支持状态重置、失败复现与批量实验。
\item \textbf{三层测评：}分别评估单轮路由、工具与回复一致性，会话策略与协商技巧，以及最终和解结果；将评分理由关联到实际执行轨迹和业务终态，定位“回复合理但操作未完成”等问题。
\item \textbf{医疗预约 AutoPE：}接入有状态用户模拟器，将体检预约拆为开场、需求探询、价值呈现、预约促成四阶段；实现阶段反馈聚合、策略候选更新与冻结评测，以模拟预约结果指导提示词演化。
\end{itemize}
